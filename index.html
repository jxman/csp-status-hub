Cloud Status Hub

Live status for AWS, Microsoft Azure, Google Cloud (GCP), and Oracle Cloud Infrastructure (OCI) in one dashboard. Check whether a cloud provider is down, see active outages and incidents by region and service, and get email alerts when a new incident starts or resolves. Updates automatically every minute.

What it shows

  • Current status for each provider: operational, degraded, or outage.
  • Active incidents with the affected regions and services and the provider's latest update.
  • A region-by-service view of where each provider is having problems.
  • An AI-generated technical and executive brief for each active incident, downloadable as a PDF.
  • Incidents resolved in the last 24 hours, plus a 90-day history of past incidents.

Where the data comes from

Everything comes from each provider's official public status feed. Cloud Status Hub is not affiliated with Amazon, Microsoft, Google, or Oracle.

  • AWS: the AWS Health Dashboard RSS feed (AWS Health Dashboard)
  • Microsoft Azure: the Azure status RSS feed (Azure status)
  • Google Cloud: the Google Cloud incidents feed (Google Cloud Service Health)
  • Oracle Cloud (OCI): the OCI status page and incident feed (OCI status)

Email alerts

Sign up for free email alerts for any or all of the four providers. You get one email when a new incident is posted and another when it resolves. Each email links to the incident on the dashboard, where its AI brief opens, and to a page where you can change providers or unsubscribe.

Common questions

How do I check if AWS, Azure, Google Cloud, or OCI is down right now?

Open this page. It loads each provider's current status as soon as you open it and refreshes every minute, so a new incident shows up without reloading.

Why does a provider show operational while I'm having problems?

Public status pages only list incidents the provider chooses to announce, usually widespread ones. AWS and Azure in particular often leave smaller, single-service or single-account problems off their public pages. For issues specific to your own account, check AWS Health in the AWS console or Azure Service Health in the Azure portal.

Is it free?

Yes. The dashboard and the email alerts are free, and you don't need an account.
